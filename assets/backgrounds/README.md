Drop background images here to customize the site background.

TWO WAYS TO USE THIS:

1) ONE IMAGE FOR THE WHOLE SITE
   Save the same image under every one of these filenames (or just
   duplicate one file with all these names):
     overview.jpg, about.jpg, experience.jpg, projects.jpg,
     education.jpg, certs.jpg, skills.jpg, contact.jpg

2) A DIFFERENT IMAGE PER PAGE
   Save a different image for each section using the exact filenames
   above — e.g. overview.jpg for the Overview page, projects.jpg for
   the Projects page, and so on.

NOTES
- Files must be named exactly as above and be .jpg (rename a .png or
  .webp to .jpg, or edit the file extension in the setSectionBackground()
  function near the bottom of index.html if you'd rather keep a different format).
- If a file for a given section is missing, that page just falls back to
  the default dark gradient — nothing breaks.
- A dark scrim is applied automatically on top of any image so text stays
  readable; you don't need to darken the photo yourself.
- Because cards use a frosted-glass blur effect, the image will show
  through them softly blurred — busy photos tend to look best here.
- Keep files reasonably small (compress to ~200–400KB each) so the site
  still loads quickly.
