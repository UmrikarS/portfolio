For each project, drop TWO files in here (same base name, different extensions):

1. A PDF export of your presentation, for the inline preview:
   - road-crash-analytics-presentation.pdf
   - one-nz-sentiment-presentation.pdf
   - olist-ecommerce-presentation.pdf
   - smartwatch-health-presentation.pdf

2. The original PPTX file, for the "Download presentation (.pptx)" button:
   - road-crash-analytics-presentation.pptx
   - one-nz-sentiment-presentation.pptx
   - olist-ecommerce-presentation.pptx
   - smartwatch-health-presentation.pptx

To get the PDF from PowerPoint: File -> Export -> Create PDF/XPS.
(Browsers can't preview .pptx directly, which is why both files are needed --
the PDF gives visitors an instant in-page preview, the PPTX lets them download
the editable original.)
